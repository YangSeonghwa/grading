# AI 자동 채점 (AI Auto-Grading)

Google Apps Script 기반의 AI 자동 채점 도구입니다. Google Classroom 제출물을 OpenAI, Claude 등의 AI API를 사용하여 자동으로 채점합니다.

## 기능

- **Google Classroom 연동**: Classroom 과제 제출물 자동 수집
- **다중 AI API 지원**: OpenAI Chat Completions, OpenAI Responses, Claude Messages, Gemini generateContent 지원
- **스프레드시트 기반 관리**: Google 스프레드시트에서 채점 큐, 제출물, 결과를 관리
- **제공업체 시트**: `AI채점_설정` 시트에 제공업체·규격(드롭다운)·키·모델을 행별로 저장하고 사이드바 드롭다운으로 선택 (사이드바 **시트 만들기/새로고침** 버튼으로 생성, Base URL이 비면 규격 기본값 사용)
- **자동 큐 처리**: 설정한 간격으로 채점 큐를 자동 처리
- **익명화 전송**: 실명·문서명·Drive ID 대신 일회용 별칭(학생01 등)으로 LLM에 전송하고, 파일명 유래 이름 토큰을 본문·피드백에서 치환
- **재시도 메커니즘**: API 호출 실패 시 자동 재시도
- **커스텀 채점 기준**: API 규격에 따른 유연한 채점 프롬프트 설정

## 설치 방법

1. 이 리포지토리의 파일을 Google Apps Script 프로젝트에 복사합니다.
2. `Code.gs`와 `sidebar.html`을 각각 스크립트 편집기에 추가합니다.
3. 필요한 Google 스프레드시트의 시트를 생성합니다:
   - `AI채점_작업` (작업 큐)
   - `AI채점_제출물` (제출물 목록)
   - `AI채점_결과` (채점 결과)

## 사용 방법

1. 스프레드시트에서 **AI 자동 채점** 메뉴를 클릭합니다.
2. **채점 사이드바 열기**를 선택하여 사이드바를 표시합니다.
3. **시트 만들기** 버튼으로 `AI채점_설정` 시트를 생성하고 행별로 API 규격을 입력합니다.
4. 제공업체를 선택하거나 API 설정을 직접 입력합니다 (키를 직접 입력하면 직접 입력이 우선합니다).
5. Google Classroom 과제를 선택하거나 직접 제출물을 업로드합니다.
6. 채점을 시작하면 자동으로 결과가 스프레드시트에 기록됩니다.

> 주의: 제공업체 시트의 API 키는 시트 열람자에게 보이므로 스프레드시트 공유 범위를 제한해 주세요.

## 설정

| 설정 항목 | 설명 | 기본값 |
|----------|------|--------|
| API 규격 | chat_completions · responses · claude · gemini | chat_completions |
| Base URL | responses·claude·gemini는 고정값 자동 입력, chat_completions는 직접 입력 | 규격별 상이 |
| 모델 | 불러오기로 조회 후 선택 또는 직접 입력 (과제 등록 시 필수) | 없음 |
| 제공업체 시트 | `AI채점_설정` 시트에 제공업체·규격·키·모델 저장 후 선택 | - |
| 만점 | 총점 | 100 |
| 점수 반영 범위 | 정량만 / 정량+정성 | 정량만 |
| AI 의심 분석 | 참고용 신호 (70 이상 high, 30~69 medium) | 끔 |
| 최대 출력 토큰 | AI 응답 최대 길이 | 65536 |
| 재시도 | 실패 시 10분 간격 최대 5회, 크레딧 부족 시 중단 | 5회 |
